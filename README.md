## 📖 About The Sheet

The **ALTA Fundamentals 111 (Pre-APEX)** curriculum is engineered to bridge the gap between basic syntax and algorithmic fluency. Designed without filler or redundant warm-ups, it establishes strong computational problem-solving intuition before moving into the high-intensity ALTA APEX series.

### Why This Sheet?
* **Zero Redundancy:** Every question in Tier 0 introduces a unique mechanical concept—covering memory boundaries, operator logic, pointer mechanics, and composite types.
* **Pure C Foundations:** Solving data structures in C enforces manual memory management, pointer arithmetic understanding, and zero-abstraction data layout.
* **Two-Tier Architecture:**
  1. **Tier 0 (Problems 1–30):** Programming Basics & Computational Thinking (Variables, Branching, Loops, Modular Functions, Arrays, and Structs).
  2. **Tier 1 (Problems 31–111):** Core Data Structures & Algorithms (Two Pointers, Recursion, Sorting, Linked Lists, Stacks, Queues, Trees, Graphs, DP, and Bit Manipulation).
